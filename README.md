### Структура репозитория

| Папка | Описание |
|---|---|
| **[`aviation/`](./aviation/)** | полный цикл работы с БД: проектирование (3NF), сложные запросы (CTE, оконные функции), представления, триггеры и функции |
| **[`winterrental/`](./winter-rental/)** | проектирование БД зимнего проката: концептуальная, логическая и физическая модели, SQL-запросы |
| **[`labs/`](./labs/)** | лабораторные работы по учебному курсу |

### Стек
* **СУБД:** PostgreSQL
* **Языки и инструменты:** SQL, Draw.io (для ER-диаграмм)
