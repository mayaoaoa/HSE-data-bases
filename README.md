## HSE Проекты и лабораторные по базам данных

### Структура репозитория

| Папка | Описание |
|---|---|
| [`final project/`](./final%20project/) | полный цикл работы с БД: создание, написание запросов (CTE, оконные функции), реализация представлений, триггеров и функций |
| [`db design/`](./db%20design/) | проектирование БД: концептуальная, логическая и физическая модели, нормализация до 2НФ, запросы |
| [`labs/`](./labs/) | лабораторные работы по курсу |

### Стек
* **СУБД:** PostgreSQL
* **Языки и инструменты:** SQL, Draw.io (для ER-диаграмм)
